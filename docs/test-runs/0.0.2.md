# Test Plan

Covers every behavior the mod implements or intends to implement. Items marked
*(not yet implemented)* exist in the design but are missing code or data. Items
marked *(needs art)* will show placeholder visuals until sprites land.

---

## 1. Animal Registration

- [x] Both animals make the standard cow sound
- [x] Adult Strawberry Cow and Chocolate Cow display correctly
- [x] You cannot buy Strawberry Cow or Chocolate Cow from Marnie
- [x] Strawberry Cow can become pregnant in a Deluxe Barn
- [x] Chocolate Cow can become pregnant in a Deluxe Barn
- [x] Calves born from Strawberry or Chocolate Cows are never Strawberry or Chocolate Cows themselves
- [x] A calf born from a Strawberry/Chocolate Cow whose `OriginalType` is "White Cow" → calf is White Cow
- [x] A calf born from a Strawberry/Chocolate Cow whose `OriginalType` is "Brown Cow" → calf is Brown Cow
- [x] After the calf grows to adulthood, it remains the correct vanilla type (White or Brown Cow)

---

## 2. Milk Production

- [x] Strawberry Cow produces **Strawberry Milk** when milked with the Milk Pail
- [x] Chocolate Cow produces **Chocolate Milk** when milked with the Milk Pail
- [x] Regular milk is produced every day (DaysToProduce = 1)
- [x] **Large Strawberry Milk** drops at high friendship / luck / Coopmaster profession (verify deluxe path actually fires — see code TODO)
- [x] **Large Chocolate Milk** drops under the same conditions
- [x] Milking a freshly transformed cow produces the *new* type's milk, not the old type's (produce is swapped to the new type on transformation if pending, or cleared if already milked)
- [x] Milking a freshly transformed cow works the first day (when the cow had pending produce at transformation time)
- [x] Transforming a cow that has already been milked today does not grant a second milking — the new type's milk appears tomorrow instead
- [x] White → Strawberry (unmilked) → Reversal Tea → milk pail yields vanilla milk same day (produce swapped back); White → Strawberry → milk → Reversal Tea → no milk today (exploit closed)
- [x] Strawberry Milk and Large Strawberry Milk appear in the shipping collection when first shipped
- [x] Chocolate Milk and Large Chocolate Milk appear in the shipping collection when first shipped

## 5. Transformation Mechanic — Happy Path

- [x] Holding **Strawberry Transformation Tea** and right-clicking (or pressing action button) on an adult **White Cow** transforms it into a Strawberry Cow
- [x] Holding **Strawberry Transformation Tea** and right-clicking an adult **Brown Cow** transforms it into a Strawberry Cow
- [x] Holding **Chocolate Transformation Tea** and right-clicking an adult **White Cow** transforms it into a Chocolate Cow
- [x] Holding **Chocolate Transformation Tea** and right-clicking an adult **Brown Cow** transforms it into a Chocolate Cow
- [x] The cow's sprite updates immediately after transformation
- [x] The original cow type is stored and can be recalled for reversal
- [x] One tea is consumed from the stack on success
- [x] A HUD success message names the cow and its new type

---

## 6. Transformation Mechanic — Reversal

- [x] Holding **Reversal Tea** and right-clicking a Strawberry Cow reverts it to its stored original type
- [x] Holding **Reversal Tea** and right-clicking a Chocolate Cow reverts it to its stored original type
- [x] A cow transformed twice (e.g. White → Strawberry → Chocolate) reverts to **White** (original type stored at first transformation, not overwritten on second)
- [x] A reverted cow's sprite updates immediately
- [x] One Reversal Tea is consumed on success
- [x] A HUD success message confirms the reversion

## 7. Transformation Mechanic — Error Cases

- [x] Using any tea on a **baby cow** shows an error message and does not transform
- [x] Using **Strawberry Tea** on a **Strawberry Cow** (already that type) shows an error and does not consume the item
- [x] Using **Chocolate Tea** on a **Chocolate Cow** shows an error and does not consume the item
- [x] Using **Reversal Tea** on a **White Cow** or **Brown Cow** (not transformed) shows an error and does not consume the item
- [x] Using any tea with **no cow within range** does nothing (no message, no item consumed)
- [x] Using any tea on a non-cow animal (chicken, goat, etc.) does nothing
- [x] The action button during an **open menu** does not trigger transformation (`Game1.activeClickableMenu != null`)
- [x] The action button during a **cutscene or event** does not trigger transformation (`Game1.CurrentEvent != null`)
- [x] Right-clicking a cow with tea does **not** open the cow status menu afterward (input is suppressed on consumed events)

## 9. Cooking Recipes — Unlock

Strawberry Ice Cream and Chocolate Ice Cream are taught by a letter from Demetrius
(`SpecialCows_DemetriusCooking`), triggered the morning after the player first collects
any special milk. Hot Chocolate is sold separately at Gus's Stardrop Saloon (see §9b).

- [ ] Demetrius's letter arrives the morning after the player first collects Strawberry Milk
- [ ] Demetrius's letter arrives the morning after the player first collects Chocolate Milk
- [ ] Picking up Large Strawberry Milk or Large Chocolate Milk also satisfies the trigger (any of the four special milks counts)
- [~] Demetrius's letter does not arrive twice (already-received check via `mailReceived`)
- [x] Opening the letter teaches Strawberry Ice Cream and Chocolate Ice Cream (not Hot Chocolate)
- [ ] On a save where the letter was received but an ice cream recipe is missing (legacy bug recovery), the `SaveLoaded` self-heal in `ModEntry` grants the missing ice cream recipes
